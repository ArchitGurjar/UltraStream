# UltraStream

UltraStream is a powerful streaming app for Android, supporting Stremio addons, Real-Debrid, and smart playlists.

## Features
- Addon support (Stremio protocol)
- Real-Debrid integration
- Smart playlists with M3U export
- Continue watching progress
- Watchlist and library management
- Hindi priority toggle
- Picture-in-picture (PiP)
- Multiple profiles

## Build
This project is built with Android Studio and Gradle.  
For releases, use GitHub Actions (provided in `.github/workflows/build.yml`).
